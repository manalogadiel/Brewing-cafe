# Brewing Café — Client Website

A modern, minimalist, and responsive informational website developed for **Brewing Café**, a cozy local café situated near a university campus. Built as part of a client-based front-end development activity.

---

## Live Demo
Check out the live deployment here:  
**[Brewing Café on GitHub Pages](https://manalogadiel.github.io/Brewing-cafe/)**

---

## Project Overview

* **Client**: Brewing Café
* **Role**: Junior Web Designer & Front-End Developer
* **Objective**: Create a streamlined, responsive promotional and informational website allowing students, campus employees, and local residents to browse the menu, explore featured combos, and contact the cafe.

---

## Key Features

* **Adaptive Layout**: Mobile-first responsive structure optimized across desktop, tablet, and mobile screens.
* **Semantic HTML**: Fully accessible semantic architecture (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`).
* **Visual Menu & Special Combos**: High-resolution imagery with tailored typographic styling and balanced promotional backgrounds.
* **Functional Contact Section**: Dedicated form styling aligned with the brand's warm, earthy coffee palette.

---

## Tech Stack

* **HTML5** (Semantic structure & accessibility)
* **CSS3** (Custom styling, Flexbox/Grid, media queries)
* **Deployment**: GitHub Pages
